# Codewars Solutions

This repository is a personal collection of my Codewars practice and solutions. It exists to document my progress and growth as a programmer over time.

## Purpose

I use Codewars to practice problem-solving and strengthen my programming fundamentals. This repository is where I keep the kata I've completed, so I can track how my approach and understanding evolve as I keep learning.

## Structure

Solutions are organized by programming language, then by kata difficulty (kyu rank):

```
codewars-solutions/
│
├── javascript/
│   ├── 8-kyu/
│   ├── 7-kyu/
│   ├── 6-kyu/
│   ├── 5-kyu/
│   └── 4-kyu/
│
└── README.md
```

JavaScript is my primary language right now, so it's the first one included here. More languages may be added as I branch out.

## Notes

- Every solution in this repository is work I've personally completed on Codewars and copied over myself.
- I may revisit older solutions later on as I learn new techniques or find better approaches — this repo reflects a work in progress, not a finished product.
